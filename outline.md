# AI Engineering Training: Outline

Three parts. We go deep on each one, one at a time.

## 1. Coding agents, in depth

How a coding agent works, and how to use it well. We use Claude Code CLI as the reference. For each feature we show the matching GitHub Copilot CLI feature, if there is one.

- How it works: the agent loop, tools, and the context window
- Giving it context: CLAUDE.md and memory
- Staying in control: permission modes, plan mode, checkpoints
- Extending it: skills, subagents, hooks, MCP, plugins
- Running it without a person: headless mode, CI, GitHub Actions
- Good habits and cost control

## 2. The ecosystem around coding agents

The tools, libraries and frameworks built around agents. Source: our agentic-ai-wiki.

- Agent frameworks and SDKs (LangGraph, Pydantic AI, OpenAI Agents SDK, Claude Agent SDK, ...)
- Harnesses and workflows for coding agents (Superpowers, GSD, BMAD, Ralph loops, ...)
- Skills and plugins
- MCP servers
- Spec-driven development and planning
- Knowledge, RAG and memory
- Browser automation, parallel agents, security

## 3. Staying up to date

This field changes every week. How to keep up without drowning.

- YouTube channels
- Email newsletters
- Changelogs and official blogs
- Our own habit: collect links, keep a shared wiki
