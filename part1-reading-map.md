# Part 1: Coding Agents, Reading Map

We don't teach Claude Code here. We point you to what to read.

- **Claude Code** is the reference tool. Its docs are the main reading.
- **GitHub Copilot CLI** is the tool we use at work. For each page we link the matching Copilot page.
- **Page priority:**
  - **Study:** read carefully.
  - **Glance:** skim for a few minutes.
  - **Skip:** not needed now.
- **Section focus** (for the sections listed under each page):
  - ⭐ **Read:** this is the important part.
  - **Skim:** look at it quickly.
  - **Skip:** ignore it for now.

Pages follow the order of the docs site: tab, then the left menu.
